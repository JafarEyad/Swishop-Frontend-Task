# SwiShop

> **Candidates:** the assignment is in [`task-requirements/TASK.md`](task-requirements/TASK.md). You have **3 days**. Fork this repository, then replace this README with your own as described there.

## Requirements

- Node.js 18.x

There is no backend to install. The starter catalog is [DummyJSON](https://dummyjson.com/). You may use another public API; see [`task-requirements/API.md`](task-requirements/API.md). Optional: `REACT_APP_API_BASE`.

## Install

```bash
npm install
```

## Run

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
